# LA VIE - Luxury Perfume House

Next.js luxury perfume store with cinematic hero, gold particles, soft smoke, animated decorative elements, Stripe checkout, cart drawer, product pages, footer, and AI assistant.

## Deploy
Upload the **contents** of this folder to GitHub so that `app`, `components`, `lib`, `public`, and `package.json` are visible at the repository root.

## Stripe
Set this environment variable in Vercel:

`STRIPE_SECRET_KEY=sk_live_or_test_key`

Stripe Checkout uses automatic European payment methods enabled in your Stripe Dashboard.
